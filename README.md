# 天地法宝（Tiandi Fabao）— Minecraft 1.21.10 / Fabric

封神演义 × 西游记主题的法宝模组。收集、祭炼、装配法宝，讨伐诸妖，还原原著神通。

> **仅支持 Minecraft 1.21.10 + Fabric**。依赖 Fabric API 与 **Accessories**（饰品栏 API）。

---

## 特性

### 法宝（9 件）
- **法器（5 件）**：乾坤圈、混天绫、打神鞭、紫金红葫芦、金刚琢 —— 装配到饰品栏法宝槽，常驻被动 + 轮盘释放
- **兵器（4 件）**：如意金箍棒、斩妖刀、降妖杵、定海神针 —— 手持即武器（挥砍 + 被动加成），右键蓄力释放
- 原著神通：乾坤圈掷出必中、混天绫缚仙索、金箍棒万钧横扫、打神鞭专打元神（无视护甲）、紫金红葫芦喊名收人、金刚琢套走兵器（缴械）

### 战斗系统
- **轮盘选择**：按住蓄力键（默认 `R`）弹出已装备法宝轮盘，拖拽选择、松手发动；蓄力越久伤害越高（满蓄 ×2.5）
- **蓄力预览**：轮盘中心实时显示蓄力百分比，满蓄变金色
- **连招**：8 秒内依次使出三件不同法宝，触发「三才合璧」范围天雷
- **器灵护主**：满蓄 + 潜行释放，召出器灵环绕攻击 8 秒
- **灵力系统**：技能消耗灵力（上限 100），装配法宝越多回灵越快

### 祭炼与成长
- **炼器炉 GUI**：祭炼（灵石升九转，每转 +10%）、喂养（灵草刷威能词条）、认主（+20%，不可交易）、合成
- **工作台合成**：全部法宝可用稀有矿物 + 怪物掉落 + 妖丹合成
- **九转品阶 / 词条 / 血脉认主**：均以数据组件存档

### 妖与妖丹
- **7 种妖**：狐妖（魅惑）、蜘蛛精（织网）、黑熊精（冲锋）、白骨精（吸血）、金角大王（葫芦吸人）、银角大王（金绳束缚）、六耳猕猴（幻术隐身）、金翅大鹏（俯冲击飞）
- **3 种妖丹**：右键召唤对应等级妖，也是合成材料
- 妖丹法宝对妖特攻：斩妖刀 ×2.5 / 降妖杵 ×3.5 / 定海神针 ×5

### 视听
- 自定义金色流光粒子、水墨风贴图、钟磬释放音、诵经环境音
- **Jade 联动**（可选）：炼器炉显示操作指南
- **指南书**：首次进服自动发放《封神西游·法宝谱》

## 安装

1. Minecraft **1.21.10** + **Fabric Loader ≥ 0.16**
2. 将以下模组放入 `mods/`：
   - **Fabric API** ≥ 0.138.0
   - **Accessories** ≥ 1.4.0-beta（必需，饰品栏 API）
   - **owo-lib**（Accessories 的前置）
   - `fabao-0.0.1-beta.jar`（本模组）
   - Jade ≥ 20.1.0（可选，炼器炉提示）
3. 启动游戏，进服自动获得指南书

## 键位（可在 选项 → 控制 → 封神西游法宝 修改）

| 键 | 默认 | 功能 |
|---|---|---|
| 法宝·蓄力释放 | `R` | 按住弹轮盘 + 蓄力，拖拽选择，松手发动 |

法器装备：右键法宝 / 饰品界面拖放；兵器：直接用，右键蓄力释放。

## 构建

```bash
gradle build        # 产物 build/libs/fabao-0.0.1-beta.jar
```

要求 **JDK 21** 与 **Gradle 8.14.3**（或自备匹配的 wrapper）。
